# Canva Portfolio Clone

HTML/React-реконструкция портфолио Sofiia Van der Vir из Canva, страницы 1–27.

Источник: [Canva — Architektur portfolio](https://www.canva.com/design/DAHRRKuCAk8/V78M6dRqqME3jUaweTcumA/view)

## Что сделано

Клон собран на базе `JCodesMore/ai-website-cloner-template`:

- Next.js 16.3, React 19.2, TypeScript 5 и App Router;
- 27 полноэкранных HTML-секций в порядке страниц Canva;
- текстовые слои сделаны обычными HTML-элементами, поэтому текст выделяется и индексируется;
- изображения загружены локально из публичных `media.canva.com` URL;
- тёплый бумажный фон, serif-заголовки, sans-serif служебный текст, правила и нижние подписи;
- `scroll-snap` для перелистывания слайдов;
- переход по колесу мыши, `ArrowUp`, `ArrowDown`, `PageUp`, `PageDown`, `Home`, `End`;
- вертикальный прогресс-рейл с кнопками перехода на страницу;
- адаптация для узких экранов и поддержка `prefers-reduced-motion`.

## Как выполнялся парсинг

### 1. Reconnaissance Canva

Скрипт `scripts/recon-canva.mjs` запускает Chrome Canary через `puppeteer-core`, открывает публичную ссылку Canva и последовательно переходит по страницам 1–27.

Для каждой страницы сохраняются:

- название страницы и номер;
- текстовые узлы (`textNodes`) из DOM;
- вычисленные CSS-стили текста;
- координаты и размеры обнаруженных изображений;
- публичные URL изображений Canva;
- viewport и служебная информация страницы.

Результат находится в:

`docs/research/canva-portfolio/canva-recon-1-27.json`

Во время reconnaissance было найдено 359 текстовых слоёв и 234 записи изображений.

### 2. Скачивание ассетов

Скрипт `scripts/download-canva-assets.mjs`:

1. читает reconnaissance JSON;
2. удаляет дубликаты URL;
3. пропускает `blob:` и не относящиеся к Canva URL;
4. скачивает 74 доступных публичных URL;
5. сохраняет файлы по UUID медиа-ресурса;
6. создаёт карту исходный URL → локальный путь.

Ассеты находятся в:

`public/sites/canva-com-237372fb/canva-portfolio-5e3226b2/images/`

Манифест находится в:

`docs/research/canva-portfolio/asset-manifest.json`

Из-за разных вариантов размера/формата одного UUID на диске получилось 59 уникальных локальных файлов при 74 скачанных URL.

### 3. Реконструкция интерфейса

Основная реализация находится в `src/app/page.tsx`.

Компонент `Slide`:

- получает данные страницы из `src/data/canva-recon-full.json`;
- выводит изображения как обычные `<img>`;
- выводит текст как `<p>`, `<h1>`, `<h2>`, `<strong>` и другие HTML-элементы;
- использует локальные координаты изображения, когда reconnaissance дал валидный прямоугольник;
- применяет отдельные композиции для обложки, оглавления и первых проектных страниц;
- не использует PNG-скриншоты как содержимое страниц.

Стили и адаптивность находятся в `src/app/globals.css`. Шрифты лежат в `public/fonts/`.

## Запуск

Из этой директории:

```bash
npm install
npm run dev
```

По умолчанию сервер запускается на `http://localhost:3000/`. Порт можно переопределить:

```bash
npm run dev -- --hostname 127.0.0.1 --port 3003
```

Production-сборка:

```bash
npm run build
```

## Повторный запуск парсинга

Если публичная Canva-ссылка снова доступна и нужно обновить данные:

```bash
node scripts/recon-canva.mjs
node scripts/download-canva-assets.mjs
npm run dev
```

URL медиа Canva могут иметь срок действия. Если ассеты перестали скачиваться, нужно заново выполнить reconnaissance и сразу после него downloader.

## Важное ограничение

Публичная ссылка Canva не отдаёт исходный React-компонентный tree, JSX, CSS-файлы или внутренние координаты редактора. Поэтому получить исходный React-код Canva «1 к 1» невозможно только по view-ссылке.

Здесь сделана реконструкция исходного дизайна средствами HTML, CSS и React на основе:

- доступного DOM публичного viewer;
- извлечённых текстовых слоёв;
- публичных медиа-ассетов;
- координат изображений;
- визуальных эталонов страниц.

Файлы из `Folio/canva-pages/*.png` используются только как визуальные референсы и не подключаются к итоговым слайдам.
